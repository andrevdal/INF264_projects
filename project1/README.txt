INF264 Project 1: Implementing Decision Trees

MAIN FILE

run_experiments.ipynb is the main file. Run all its cells to execute the tests, model selection, model evaluation, generate plots and feature importance analysis.

FILES

- run_experiments.ipynb: Runs the experiments and displays the results.
- decision_tree.py: Contains our decision tree code and the function that measures feature importance.
- requirements.txt: Lists the required Python packages.
- data/churn-data.csv: Dataset used in the experiments.

HOW TO RUN

1. Open a terminal in the folder containing run_experiments.ipynb and install the dependencies:

   python -m pip install -r requirements.txt

2. Open run_experiments.ipynb in VS Code with the Python and Jupyter extensions installed.

3. Select the Python environment where the dependencies were installed.

4. Restart the notebook kernel and run all cells from top to bottom. The working directory should be the folder containing the notebook.

All result tables and figures appear in the notebook. 

IMPORTANT

The dataset must remain at data/churn-data.csv.
